# 📘 الدليل الفني الشامل: نظام Price Action الاحترافي لمنصة MT5 (الإصدار 4.20)

تمت إعادة هيكلة هذا النظام الخوارزمي وتدقيقه هندسياً وميدانياً بنسبة 100% ليتطابق بدقة مطلقة مع القواعد الأصلية لكتاب **Price Action Trading (الـ 97 صفحة - نيل فولر)**، مع الفصل التام والصارم بين **استراتيجية الكتاب الحرفية المجردة (`MODE_BOOK_EXACT`)** و**الفلاتر الكمية المتقدمة الاختيارية (`MODE_ENHANCED`)**، مع التحقق الكامل عبر اختبارات بيئة التشغيل الحية في MetaTrader 5 Strategy Tester.

---

## 🎛️ أولاً: التبديل الصارم بين الأنماط (Mode Selector)

يحتوي الإكسبرت في مقدمة الإعدادات على خيار التبديل الجذري:

```mql5
InpStrategyMode = MODE_BOOK_EXACT;   // النمط (أ): استراتيجية الكتاب الحرفية
InpStrategyMode = MODE_ENHANCED;     // النمط (ب): الاستراتيجية المتقدمة بالفلاتر
```

### 1. النمط (أ): `MODE_BOOK_EXACT` (الكتاب الحرفي)
في هذا النمط، تُعزل وتُعطل تماماً جميع المؤشرات الإضافية:
* ❌ **EMA: معطل تماماً** (الاتجاه يُحدد حصرياً من هيكل حركة السعر والقمم والقيعان المتتالية HH/HL أو LH/LL).
* ❌ **RSI: معطل تماماً**.
* ❌ **VSA: معطل تماماً**.
* ❌ **Order Blocks / FVG / POI: معطلة تماماً**.
* ✅ **الاعتماد الكلي على:**
  1. هيكل السوق السعري عبر القمم والقيعان المؤكدة (Confirmed Pivot Swings).
  2. مستويات الدعم والمقاومة الأفقية الحقيقية مع خاصية **تبادل الأدوار (Level Flips)**.
  3. توافق منتصف الموجة الدافعة السابقة (**50% Swing Retracement**).
  4. نماذج الشموع الثلاثة المعيارية:
     - **Pin Bar:** نسبة ذيل $\ge 2/3$ ونسبة جسم $\le 1/3$ مع بروز واضح (صفحة 55).
     - **Inside Bar:** استمرار مع الاتجاه بتوافق، أو انعكاس عند مستويات دعم/مقاومة مؤكدة (صفحة 63).
     - **Fakey:** كسر كاذب صريح بنقاط كافية يدعم 1 أو 2 أو 3 شموع داخلية متداخلة (Nested Fakey).
  5. الدخول بأمر معلق عند منتصف البين بار (**50% Limit Entry**) لتقليص الوقف للنصف أو دخول ماركت مباشر.

### 2. النمط (ب): `MODE_ENHANCED` (الاستراتيجية المطوّرة)
في هذا النمط، تظل استراتيجية البرايس أكشن الأصلية هي الأساس المشغل، مع إضافة طبقات ترشيح إحصائية متقدمة:
* موفنجات EMA السريعة والبطيئة لتأكيد زخم الاتجاه.
* مؤشر RSI لمنع الدخول في ذروة التشبعات السعرية.
* فوليوم سبريد VSA لرصد بارات الجهد المرتفع وامتصاص السيولة.
* مناطق العرض والطلب المؤسسية الكبرى (HTF Order Blocks) وفجوات السيولة (FVG/Fair Value Gaps).

## 🎯 ثانياً: قواعد التوافق لشمعة Inside Bar ونموذج Fakey المتداخل

### 1. قواعد توافق الشمعة الداخلية (Inside Bar Confluence Routing)
تم فض أي تداخل بين الاستمرار والانعكاس هندسياً عبر دالة فحص التوافق `ValidateConfluence`:
* **نمط الاستمرار (Continuation):** يتطلب توفر الاتجاه الصاعد/الهابط المؤكد من هيكل السوق بالقمم والقيعان، بالإضافة إلى توافق إضافي:
  $$\text{Continuation} = \text{Trend} + (\text{Key S/R Level} \lor 50\%\text{ Swing Retracement})$$
* **نمط الانعكاس (Reversal at Key Levels):** يُسمح به حتى لو كان السوق في نطاق عرضي أو عكس الاتجاه الفرعي، شريطة وجود **مستوى دعم أو مقاومة أفقي مؤكد (Key S/R Level)** تفاعلت معه الشمعة الأم.

### 2. نموذج الفايكي متعدد الشموع المتداخلة (Nested Fakey Mechanics)
يدعم النظام هندسياً نموذج الفايكي الكلاسيكي والمتداخل بدقة:
* يتعرف الكود على الهيكل سواء احتوى على شمعة داخلية واحدة، أو شمعتين (Double Inside Bars)، أو 3 شموع داخلية (Triple Nested Inside Bars) محتواة بالكامل داخل الشمعة الأم (Mother Bar).
* يتم قياس الكسر الكاذب بالنسبة للحدود الكلية للهيكل السعري (`structureHigh` / `structureLow`).
* يشترط أن يتجاوز الكسر الكاذب الحد الأدنى من النقاط (`InpFakeyMinBreakPoints`) لمنع اعتبار الذيول العشوائية كسراً كاذباً، مع اشتراط الإغلاق عائداً داخل الهيكل أو تشكيل ذيل رفض صريح.

## 🛡️ ثالثاً: المعمارية الهندسية الصارمة للتنفيذ وإدارة الأوامر في MT5

1. **نمط ملء الأوامر المتوافق مع البروكر (Symbol-Aware Filling Mode):**
   * لا يتم فرض `ORDER_FILLING_FOK` بشكل ثابت تجنباً لرفض الأوامر لدى وسطاء الفوركس؛ بل يقرأ الإكسبرت قناع `SYMBOL_FILLING_MODE` ديناميكياً ويختار نمط الملء المدعوم تلقائياً (`FOK` أو `IOC` أو `RETURN`).

2. **التحقق الإلزامي من رموز استجابة البروكر (Strict Trade Retcodes):**
   * كل عملية إرسال أمر (`Buy`, `Sell`, `BuyLimit`, `SellLimit`, `BuyStop`, `SellStop`) أو تعديل صفقة (`PositionModify`) أو حذف أمر معلق (`OrderDelete`) تخضع للتحقق الصارم من `ResultRetcode() == TRADE_RETCODE_DONE` (10009).
   * لا يُكتفى بالقيمة المنطقية العائدة من فئة `CTrade`.
   * في صفقات الماركت، يتم تتبع تذكرة الصفقة الحقيقية عبر ربط التذكرة المنفذة `ResultDeal()` بمعرف الصفقة `DEAL_POSITION_ID`.

3. **مطابقة مسافات التجميد والوقف لدى البروكر (Freeze & Stops Level Validation):**
   * قبل إرسال أو تعديل أي أمر، يتحقق النظام من ألا تقل مسافة الوقف أو الهدف عن:
     $$\text{MinDistance} = \max(\text{SYMBOL\_TRADE\_STOPS\_LEVEL}, \text{SYMBOL\_TRADE\_FREEZE\_LEVEL}) \times \text{Point}$$

4. **نظام OCO الهجين ومقاومة الانقطاع (Crash Recovery OCO Engine):**
   * عند إرسال أمري اختراق متقابلين للشمعة الداخلية (BuyStop و SellStop)، يتم تتبعهما عبر معرف موحد يبدأ بـ `IB_OCO_<Timestamp>`.
   * **حل معضلة الحد الأقصى لكومنتات MT5 (31 حرفاً):** تم وضع التاج الفريد في بداية الكومنت لضمان عدم اقتطاعه نهائياً من قبل المنصة عند إعادة التشغيل.
   * **الفحص في الذاكرة الحية:** يتم التحقق من تفعيل الأمر المعلق عبر `HistoryOrderSelect` + `ORDER_STATE_FILLED` بدلاً من فحص المراكز المباشر.
   * **الفحص عند إعادة التشغيل:** في حال إغلاق المنصة وإعادة فتحها، يقوم الإكسبرت بمسح المراكز المفتوحة والأوامر المعلقة، وإلغاء أي أمر معلق يتطابق مع صفقة مفعلة بنفس الرمز فوراً بنسبة 100% لمنع وجود أوامر يتيمة (Zero Orphan Orders).

5. **ثبات قيمة المخاطرة الأصلية لنقل الوقف (Break-Even & Trailing Risk Invariance):**
   * تم حفظ قيمة `initialRiskPoints` في مصفوفة دائمة ومتغيرات طرفية عامة (`GlobalVariableSet`) بحيث لا تنهار قيمة المخاطرة إلى الصفر عند نقل الوقف لنقطة الدخول، مما يحافظ على استمرارية ملاحقة الأرباح بنسب R:R الرياضية بدقة متناهية.
